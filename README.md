# CSA05110-CNS-Lab-Experiments-
CSA05110 - Cryptography & Network Security Lab Experiments
This repository contains a collection of C programs implementing classical cryptography algorithms and cryptanalysis techniques, developed as part of the CSA05110 Cryptography & Network Security (CNS) Lab course.

📜 Overview
Each experiment focuses on a fundamental concept in classical cryptography, including encryption, decryption, and cryptanalysis of various cipher techniques.

🛠️ Technologies Used
	* Language: C, Python
	
🎯 Learning Objectives
	* Understand classical encryption techniques
	* Implement substitution and transposition ciphers
	* Perform cryptanalysis using frequency attacks
	* Strengthen fundamentals of Cryptography & Network Security
